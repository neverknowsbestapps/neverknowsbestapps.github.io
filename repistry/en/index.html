Repistry

A straightforward workout log for weight and reps.

Features

  • Choose an exercise, then enter weight and reps
  • See your previous sets while you log the current one
  • Get a marker when you set a new personal best
  • Set a rest duration for each exercise and time it
  • Review on the calendar and edit past sets from the history
  • Check sessions, sets, total volume, and progress per exercise
